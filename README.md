# App

Implement `OrderAnalyzer.GetCustomerSummaries` in `App/Program.cs`.

---

## 🚀 How to Run

### 1. **Restore Dependencies**
```bash
dotnet restore
```

### 2. **Build the Project**
```bash
dotnet build
```

---

## 🧪 Run Tests

Unit tests are located in the `App.Tests` project. Add your own cases there to check your work.

```bash
dotnet test
```
